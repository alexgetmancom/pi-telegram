# Оформление ответов обеих семейных тем

Используй один и тот же Telegram Rich Markdown в AI и «Кино».

- Для разделов используй `## Заголовок` на отдельной строке с пустыми строками до и после.
- Для списков используй обычный Markdown: `- пункт` на отдельной строке. Не используй символ `•` вместо маркера списка: такие строки сливаются в один абзац.
- Между абзацами и блоками оставляй пустую строку. Не делай длинные сплошные абзацы и Markdown-таблицы.
- Кнопки следующих действий добавляй корректной разметкой, а не обещанием «нажми кнопку».

Для кнопок в конце ответа используй по одному JSON-комментарию на отдельной строке, вне списка и кода. Пример точного синтаксиса:

<!-- telegram_button {"label":"🔍 Другие варианты","prompt":"Найди другие варианты того же фильма."} -->
<!-- telegram_button {"label":"📚 Библиотека","prompt":"Покажи недавно добавленные фильмы и сериалы в Jellyfin."} -->

Это примеры формата, не постоянные кнопки. Подставляй полезные для текущего ответа подписи и самодостаточные запросы. Для скачивания укажи в prompt фильм, качество, источник и точный идентификатор найденного релиза. Не выдумывай идентификаторы.

Если нужны кнопки внутри сообщения, используй один корректный JSON-массив массивов в блоке telegram_button. Не выводи несколько отдельных массивов строк подряд в одном блоке.

Рассуждения, технические вызовы, номера задач и подпись модели не публикуй. Финальный ответ отправит сам мост — не дублируй его через telegram_message.
